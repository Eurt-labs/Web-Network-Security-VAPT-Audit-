# Web & Network Security VAPT Audit

A complete Vulnerability Assessment and Penetration Testing (VAPT) lab project focused on Web Application Security and Network Security testing in a simulated enterprise environment.

## Key Highlights

* Designed and deployed a virtualized VAPT lab environment using VMware.
* Configured attacker and target systems including:

  * Kali Linux
  * Ubuntu Server
  * Vulnerable Laravel Applications
  * DVWA
  * OWASP Juice Shop
  * WebGoat
* Performed:

  * Network Enumeration
  * Port Scanning
  * Vulnerability Scanning
  * Web Application Pentesting
  * Service Exploitation
* Assessed vulnerabilities based on OWASP Top 10 standards:

  * SQL Injection
  * Cross-Site Scripting (XSS)
  * Broken Authentication
  * IDOR
  * Security Misconfiguration
  * File Upload Vulnerabilities
  * Command Injection
* Conducted security scans using:

  * Nmap
  * Nessus
  * Burp Suite
  * OWASP ZAP
  * SQLMap
  * Hydra
  * Metasploit
* Identified vulnerabilities such as Clickjacking and insecure configurations with remediation guidance.

## Skills Demonstrated

* VAPT Methodology
* Network Security Assessment

* Linux Server Hardening
* Vulnerability Scanning
* OWASP Testing
* Security Reporting
* Exploitation Techniques
